# Maximizing Go's Capabilities with the WebAssembly System Interface

KubeCon + CloudNativeCon Europe 2024, 19th–22nd March 2024

- Rajiv Ranjan Singh
- Achille Roussel

## About

The state of WebAssembly in Go through WASI preview 1: how WASI support arrived in the
Go toolchain, how to build for the `wasip1` target today, and where the work goes next
— told alongside the open-source community effort that landed it.
